# Для Моли 💗 — персональный романтический сайт

Адаптивный сайт на Next.js App Router + TypeScript + Tailwind CSS + Motion. Внутри: приветствие, интерактивный конверт, фотоальбом с увеличением фотографий, письмо, раскрывающиеся карточки-признания, музыкальный плеер и финальный сюрприз.

## 1. Что нужно установить

- Node.js LTS (рекомендуется версия 20 или 22)
- Git (для публикации через GitHub)
- Редактор кода, например VS Code

## 2. Запуск на компьютере

Открой терминал в папке проекта и выполни:

```bash
npm install
npm run dev
```

Открой адрес, который покажет терминал, обычно `http://localhost:3000`.

Проверка production-сборки:

```bash
npm run build
npm run start
```

## 3. Как добавить фотографии

1. Скопируй фотографии в формате JPG, JPEG, PNG или WebP в `public/photos/`. Для скорости лучше уменьшить длинную сторону примерно до 1600 px.
2. Открой `src/data/content.ts` и добавь в массив `memories` путь к каждому изображению и подписи:

```ts
export const memories = [
  { image: '/photos/photo-1.png', label: 'Наш момент', caption: 'Твоя подпись к фото' },
];
```

Добавь все фотографии, которые хочешь показать; для каждого пути укажи точное имя файла с учётом регистра и расширения. Карточки сохраняют пропорции и обрезают изображение без растягивания.

## 4. Как добавить музыку

Скопируй аудиофайлы в `public/music/`. При запуске Next.js автоматически найдёт файлы MP3, M4A, AAC, OGG, OPUS, WAV и FLAC; их названия менять не нужно. Компактный плеер доступен на всей странице, а треки повторяются по кругу. Браузер может запретить автовоспроизведение до первого взаимодействия — тогда появится кнопка включения музыки.

Если папка `public/music/` пуста, плеер сообщит, что музыка ещё не добавлена. Для лучшей совместимости браузеров рекомендуется MP3.

## 5. Как персонализировать письмо и причины

Открой `src/data/content.ts`:

- `loveLetter` — текст письма. Сохраняй `\n` для новых строк.
- `reasons` — массив из 6 причин. Замени каждую на правдивую, личную деталь.
- `memories` — подписи к фотографиям.

В проекте намеренно не придуманы ваши реальные воспоминания. Примеры легко заменить на ваши слова.

Если хочешь изменить обращение «Моля», найди текст `Моля` в `src/components/LoveSite.tsx` и `src/data/content.ts`.

## 6. Бесплатная публикация на Vercel

1. Создай репозиторий на GitHub.
2. В терминале проекта выполни:

```bash
git init
git add .
git commit -m "Create romantic website for Molia"
git branch -M main
git remote add origin https://github.com/ТВОЙ-ЛОГИН/ИМЯ-РЕПОЗИТОРИЯ.git
git push -u origin main
```

Заменяй URL репозитория на свой. Если Git уже настроен, повторно `git init` не нужен.

3. Войди на https://vercel.com/ через GitHub.
4. Нажми **Add New → Project** и импортируй репозиторий.
5. Framework Preset должен определиться как **Next.js**. Build Command и Output Directory оставь по умолчанию. Переменные окружения не нужны.
6. Нажми **Deploy**. После сборки Vercel выдаст ссылку `имя-проекта.vercel.app`.
7. При следующих `git push` Vercel автоматически обновит сайт.

Тариф Vercel Hobby предназначен для личного и некоммерческого использования и имеет лимиты. Ознакомься с действующими условиями Vercel перед публикацией.

## 7. Перед отправкой ссылки

- Проверь сайт на телефоне.
- Проверь подписи и пути всех фотографий в галерее.
- Перепиши письмо и карточки своими словами.
- Помни: статический сайт не скрывает файлы из `public`. Любой, у кого есть ссылка, потенциально сможет увидеть размещённые фотографии. Не загружай туда то, что должно оставаться строго приватным.
